# Sticker credits

The sticker artwork in this folder comes from two open-licensed emoji sets.
The files were resized to 128/160 px and re-encoded as WebP (animated Noto
files keep every second frame). The "Caro" stickers are drawn in code
(`client/src/components/comms/CaroSticker.tsx`) and belong to this project.

## `noto/`: Noto Emoji animations

Animated emoji from [Noto Emoji](https://googlefonts.github.io/noto-emoji-animation/) by Google,
licensed under [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).
Modified: resized, frame rate halved, re-encoded.

## `fluent/`: Fluent Emoji (3D)

From [microsoft/fluentui-emoji](https://github.com/microsoft/fluentui-emoji). Modified: resized, re-encoded.
